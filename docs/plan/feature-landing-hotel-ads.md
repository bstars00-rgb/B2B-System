## 0. 한 줄 요약

로그인 화면 왼쪽 광고판을 호텔 광고 위주로 바꾼다. 방문자가 스크롤하면 객실 장면이 하나씩 넘어가고, 마지막 장면은 호텔 외관과 "객실·요금 보기" 버튼이다. 로그인 패널은 오른쪽에 그대로 있어 언제든 로그인할 수 있다.

## 1. 원칙 세 가지

1. 스크롤이 이야기를 진행한다. 페이지가 스크롤을 가로채지 않는다(휠 캡처·강제 스냅 없음).
2. 객실 먼저, 외관 마지막. 모든 호텔 광고는 외관 장면으로 끝난다.
3. 광고에 요금·가격 문구를 넣지 않는다. 요금은 로그인 후에만 보인다(마켓 전용요금 태그 결정과 같은 기조).

## 3. 장면 구성

| 장면 | 내용 | 화면 문구 |
|------|------|-----------|
| 1 첫 객실 | 대표 객실 사진 | "Featured hotel" · 호텔명 · 도시 · 성급 |
| 2~3 객실 | 다음 객실 사진 | 객실명 + 사실 한 가지(면적·침대·전망) |
| (선택) 부대시설 | 로비·조식·수영장 | 시설명 + 사실 한 가지 |
| 마지막 외관 | 외관 사진 | 호텔명 또는 위치 정보 · CTA "View rooms & rates" |

- 장면당 스크롤 100vh(80~120 조정). 사진 크로스페이드, 1.08→1.00 천천히 줌, 문구 슬라이드업, 배경 톤 전환. 위로 스크롤하면 역재생.
- 장면 3~6개, 객실 2개 이상, 마지막은 반드시 외관.
- CTA: 비로그인이면 로그인 패널로 포커스 + "{호텔} 요금은 로그인 후 확인", 로그인 후 Create Booking에 호텔 프리필. 로그인 상태면 바로 Create Booking.

## 4. 형식

| 형식 | 방식 | 용도 |
|------|------|------|
| 사진 스토리(기본·1차 출시) | 정지 사진 + 크로스페이드·줌·문구 움직임. 사진 4~6장이면 디자이너 없이 게시 | 모든 호텔 광고 |
| 비디오 스크럽(프리미엄·이후) | 5~8초 영상을 스크롤에 맞춰 프레임 재생(WebP 90~150장 또는 영상 시간 연동). 참고 영상의 "쌓이는" 효과. 호텔 사진으로 이미지→영상 생성 가능 | 추천·유료 캠페인 |
