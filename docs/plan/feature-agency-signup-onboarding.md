# 기능 기획 — 마켓플레이스 가입 자동 안내 메일 (사업자등록증 요청 · 계정 오픈 안내)

> **작성일**: 2026-11-19 · **트랙**: B (Marketplace 고도화) · **차수**: 미정 · **상태**: 기획 초안
> **요청 출처**: 현업(2026-11-19, Aiden). 콤파스프리가 마켓플레이스에서 직접 가입했고, GSM(Grace)이 계정 오픈·안내 메일·매뉴얼 첨부·사업자등록증 요청을 모두 손으로 처리했다. 가입 후 안내를 자동으로 보내고 싶다.

---

## 0. 한 줄 요약

여행사가 ohmyhotel.biz에서 가입하면 **바로 사업자등록증을 요청하는 메일**이 나가고, 서류를 받은 GSM이 계정을 **Active로 바꾸면 이용 매뉴얼을 첨부한 오픈 안내 메일**이 자동으로 나간다. GSM은 서류 확인과 승인 버튼만 누른다.

## 1. 지금은 이렇게 한다

| 단계 | 지금 | 누가 |
|------|------|------|
| 가입 | ohmyhotel.biz/join 4단계: 약관 동의 → 회사 정보 → 관리자 등록 → 완료 | 여행사 |
| 가입 알림 | 정해진 알림 없음 (GSM이 ELLIS에서 확인) | GSM |
| 계정 오픈 | ELLIS에서 상태 변경 | GSM |
| 안내 메일 | 직접 작성. 오픈 완료, 선불 결제 안내, 매뉴얼 PDF 첨부, 사업자등록증 회신 요청 | GSM |
| 사업자등록증 | 메일 회신으로 받음 | 여행사 → GSM |

- 가입 화면 2단계는 회사명, 회사 유형, 국가, 주소, 대표 연락처, 대표자명, **사업자등록번호(중복 확인)**를 받는다. 서류 첨부 칸은 없다.
- 콤파스프리 건(11-19)은 계정을 먼저 열고 서류를 나중에 요청했다. 이번 기획은 **서류를 받은 뒤에 연다**로 순서를 바꾼다(§9 결정 1).

## 2. 바뀐 흐름

```
여행사 가입 완료
  → [자동] 메일 ① 가입 접수 + 사업자등록증 요청 (업로드 링크)
  → [자동] GSM 알림: 신규 가입
여행사가 서류 업로드 (또는 메일 회신 → GSM이 ELLIS에 첨부)
  → [자동] GSM 알림: 서류 접수
GSM이 서류 확인 → Active로 변경 (반려하면 메일 ③)
  → [자동] 메일 ② 계정 오픈 안내 + 이용 매뉴얼 첨부
  → [자동] 마켓 공통 규칙 적용 (Dotbiz Market 트레이더 300427)
서류가 안 오면 → [자동] 리마인드 D+3 · D+7 → D+30 만료
```

## 3. 상태

| 상태 | 뜻 | 들어가는 때 | 나가는 메일 |
|------|----|-------------|-------------|
| 가입 접수 | 가입은 끝났고 서류 대기 | 가입 완료 | ① 서류 요청 |
| 서류 접수 | 서류가 들어왔고 GSM 확인 대기 | 업로드 또는 GSM 첨부 | 없음 (GSM 알림) |
| 활성 (Active) | 로그인·예약 가능 | GSM 승인 | ② 오픈 안내 |
| 반려 | 서류가 맞지 않음 | GSM 반려 | ③ 재제출 요청 |
| 만료 | 30일 동안 서류 없음 | 자동 | 없음 (GSM 알림) |

ELLIS 거래처의 Trade Status(Pending 등)와 어떻게 맞출지는 Tracy와 확인한다. 새 상태를 늘리기 어렵다면 Trade Status는 Pending/Active만 쓰고 "서류 접수 여부·반려·만료"는 별도 필드로 둔다.

## 4. 자동 메일

### 4.1 공통

| 항목 | 내용 |
|------|------|
| 보내는 사람 | 오마이호텔 마켓플레이스 대표 주소(§9 결정 3). 회신 주소는 담당 GSM |
| 참조 | 담당 GSM (GSM은 국가별 배정표로 자동 지정) |
| 받는 사람 | 가입 때 입력한 관리자 이메일. 대표 이메일이 다르면 함께 |
| 언어 | 가입 화면 언어(EN·KO·JA·ZH·VI). 해당 언어 문안이 없으면 영어 |
| 문안 관리 | ELLIS에서 언어별로 수정(배포 없이). 변수 {회사명} {담당자명} {관리자 아이디} {사업자등록번호} {업로드 링크} {링크 만료일} {담당 GSM} {결제 조건} |
| 기록 | 거래처 화면에 발송 이력: 메일 종류, 언어, 받는 사람, 시각, 성공/반송 |
| 반송 | 반송되면 GSM 알림. 이메일 수정 후 다시 보내기 버튼 |

### 4.2 메일 ① 가입 접수 + 사업자등록증 요청 (가입 즉시)

**제목** [오마이호텔 마켓플레이스] 가입 신청이 접수되었습니다. 사업자등록증을 보내 주세요

> 안녕하세요, {담당자명}님.
> 오마이호텔 마켓플레이스에 가입 신청해 주셔서 감사합니다.
>
> {회사명}의 가입 신청이 접수되었습니다. 계정을 열려면 사업자등록증 사본이 필요합니다. 아래 버튼으로 올려 주세요. 이 메일에 첨부해 회신하셔도 됩니다.
>
> [사업자등록증 올리기] ({링크 만료일}까지)
>
> 서류를 확인하면 계정을 열고 이용 안내 메일을 다시 보내 드립니다.
>
> 신청 정보
> - 회사명: {회사명}
> - 사업자등록번호: {사업자등록번호}
> - 관리자 아이디: {관리자 아이디}
>
> 문의: {담당 GSM}
> 오마이호텔 드림

해외 여행사 문안은 "사업자등록증 또는 해당 국가의 사업자 등록 서류"로 쓴다.

### 4.3 메일 ② 계정 오픈 안내 (Active 변경 시)

Grace가 보낸 메일(11-19)을 기준으로 만들고, 서류는 이미 받았으니 회신 요청 문장은 뺀다.

**제목** [오마이호텔 마켓플레이스] 계정이 열렸습니다

> 안녕하세요, {담당자명}님.
> 보내 주신 서류를 확인하고 {회사명} 계정을 열었습니다. 지금 바로 로그인해 이용하실 수 있습니다.
>
> - 로그인: https://ohmyhotel.biz/login
> - 아이디: {관리자 아이디}
> - 결제: {결제 조건}
> - 직원 계정: 로그인 후 Member list > Staff list에서 추가할 수 있습니다.
>
> 이용 매뉴얼을 첨부했습니다.
>
> 담당: {담당 GSM}
> 감사합니다.
> 오마이호텔 드림
>
> 첨부: B2B 파트너스 매뉴얼.pdf

- {결제 조건} 기본값(신규 = 선불): "선불입니다. 취소 마감일 전에 카드 결제나 입금으로 진행해 주세요." 후불 계약 업체는 GSM이 승인할 때 문안을 고른다.
- 비밀번호는 메일에 넣지 않는다(가입 때 본인이 정함).

### 4.4 메일 ③ 서류 재제출 요청 (반려 시)

**제목** [오마이호텔 마켓플레이스] 사업자등록증을 다시 보내 주세요

> {회사명}에서 보내 주신 서류로는 확인이 어렵습니다. 사유: {반려 사유}
> 아래 버튼으로 다시 올려 주세요. [사업자등록증 올리기]

반려 사유는 GSM이 목록(흐림·다른 회사 서류·번호 불일치·기타)에서 고르고 한 줄 덧붙인다.

### 4.5 리마인드

| 시점 | 내용 |
|------|------|
| D+3, D+7 | 메일 ①을 짧게 다시 보냄 ("아직 서류를 받지 못했습니다") |
| D+14 | GSM 알림만 (직접 연락할지 판단) |
| D+30 | 만료. GSM 알림. 여행사가 다시 서류를 올리면 서류 접수로 돌아감 |

## 5. 사업자등록증 받기

| 항목 | 내용 |
|------|------|
| 업로드 링크 | 메일 ①에 개인 링크(로그인 없이 열림, 14일 유효, 거래처 1곳 전용). PDF·JPG·PNG, 10MB 이하, 최대 3개 |
| 저장 | ELLIS 거래처(Company Master)의 첨부 파일. GSM·재무만 열람 |
| 메일 회신으로 온 경우 | GSM이 ELLIS 거래처에 첨부하고 "서류 접수"를 누름 (1단계). 대표 메일함 첨부 자동 인식은 2단계 검토 |
| 확인 | 사업자등록번호가 가입 때 입력한 번호와 같은지 GSM이 확인. 번호가 다르면 반려 |
| 개인정보 | 개인사업자 등록증에는 대표자 개인정보가 있다. 열람 권한 제한, 보관 기간은 거래 종료 후 법정 기간 |

대안(§9 결정 2): 가입 화면 2단계에 첨부 칸을 넣으면 메일 ① 없이 바로 "서류 접수"가 된다. 첨부를 건너뛴 가입자에게만 메일 ①을 보낸다.

## 6. GSM 쪽 화면과 알림 (ELLIS)

| 기능 | 내용 |
|------|------|
| 신규 가입 목록 | 회사명, 국가, 가입일, 상태, 서류, 담당 GSM, 경과일. 상태별 필터 |
| 거래처 상세 | 서류 미리보기, [승인] [반려], 결제 조건 선택, 메일 발송 이력, [메일 다시 보내기] |
| 알림 | 신규 가입 · 서류 접수 · D+14 미제출 · 만료 · 메일 반송. 담당 GSM에게 메일(Teams는 2단계) |
| 담당 배정 | 국가 → GSM 배정표. 배정표에 없는 국가는 Global Sales 공용 담당 |

## 7. Active로 바뀔 때 함께 처리할 것

- **마켓 공통 규칙 적용.** 지금은 새 에이전시가 Dotbiz Market 트레이더(300427)의 Include/Exclude 규칙을 트레이더를 다시 저장할 때까지 받지 못한다(마켓 전용요금 가이드의 알려진 이슈). 승인과 동시에 규칙이 적용되어야 마켓 전용 요금이 처음부터 보인다. Tracy가 진행 중인 수정 태스크와 묶는다.
- 결제 조건(선불 기본) 저장.
- 메일 ② 발송.

## 8. 예외

| 상황 | 처리 |
|------|------|
| 같은 사업자등록번호로 다시 가입 | 가입 화면 중복 확인에서 막힘(지금과 같음). 메일 없음 |
| 서류 대신 다른 파일 | 반려 → 메일 ③ |
| 관리자 이메일 오타·반송 | GSM 알림, 이메일 수정 후 다시 보내기 |
| GSM이 서류 없이 먼저 열어야 할 때 | 승인 화면에서 "서류 나중에 받기" 선택 + 사유 입력. 메일 ②에 사업자등록증 회신 요청 문장이 붙음(지금 Grace 메일과 같은 형태) |
| API 연동 거래처의 포털 계정 | 이 흐름 대상 아님 (GSM이 직접 생성) |

## 9. 결정 필요

| # | 항목 | 제안 |
|---|------|------|
| 1 | 오픈 순서 | 서류를 받은 뒤 오픈. 예외는 "서류 나중에 받기" + 사유 |
| 2 | 서류 받는 방법 | 1단계는 메일 ①의 업로드 링크. 가입 화면 첨부 칸은 2단계 |
| 3 | 보내는 주소 | 대표 주소(예: sales@ohmyhotel.com) + 회신 주소 담당 GSM. noreply는 쓰지 않음(회신으로 서류가 오기 때문) |
| 4 | GSM 국가 배정표 | 국가별 담당자 명단 필요 |
| 5 | 리마인드·만료 일수 | D+3, D+7, D+14 알림, D+30 만료 |
| 6 | 매뉴얼 언어 | 지금 있는 것은 한국어 PDF(Grace 첨부본)와 영어판(B2B Partner Manual_EN). 일본어·중국어·베트남어판은 영어로 대체할지, 새로 만들지 |
| 7 | 승인 자체도 자동으로 할지 | 하지 않음. 마켓 요금은 등록 여행사에게만 보이므로 사람이 한 번 확인 |
| 8 | 차수 | 미정 |

## 10. 지표

| 지표 | 정의 |
|------|------|
| 가입 → 활성화 소요 시간 | 가입 완료부터 Active까지 |
| 서류 회신율 | 가입 후 30일 안에 서류를 낸 비율 |
| GSM 수작업 메일 | 가입 건당 GSM이 직접 쓴 메일 수 (목표 0) |
| 첫 예약까지 | Active 후 첫 예약까지 걸린 일수 |

## 11. 진행 제안

1. **1단계(필수)**: 메일 ①② + 매뉴얼 첨부 + 상태(가입 접수·서류 접수·활성) + 발송 이력 + GSM 알림(신규 가입·서류 접수) + Active 시 마켓 공통 규칙 적용
2. **2단계**: 업로드 링크 고도화(가입 화면 첨부 칸), 리마인드·만료, 반려 메일 ③, 신규 가입 목록 화면, Teams 알림
3. Tracy에게 ELLIS 쪽 확인: Trade Status 값, 메일 발송 기능 유무, 거래처 첨부 저장 위치, 300427 규칙 자동 적용 수정 일정
